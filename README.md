# Sigma Saint-Junien 87 — Charlery BURNER

Site immobilier bilingue EN / FR, en HTML, CSS et JavaScript, sans compilation.

## Modifier le site

- `dist/index.html` : version anglaise.
- `dist/fr.html` : version française.
- `dist/styles.css` : mise en page, couleurs et adaptation mobile.
- `dist/script.js` : galerie photo et changement de langue.
- `dist/assets/` : photographies, icônes CB et image de partage.

Pour un aperçu local : `python -m http.server 8000 --directory dist`, puis ouvrir http://localhost:8000.

Hébergement statique : utiliser `dist` comme dossier publié, sans commande de build.
